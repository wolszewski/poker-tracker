# 01: Walking skeleton

**What to build:** A Vite + React + TypeScript app that runs locally and shows a single phone-first screen with an empty Night: no Players yet, and a totals bar showing 0 for total Buy-ins, total Cash-outs and the Discrepancy. The Night module exists as a plain TypeScript module with no React or browser dependencies, and can create an empty Night. Vitest is set up. See `.scratch/poker-night-tracker/spec.md`, and use the vocabulary in `CONTEXT.md`.

**Blocked by:** None (can start immediately)
